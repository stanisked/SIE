# Shadow RGB: слепая выборка после проверки оператором (31.10.2026)

Исходная запись: 1200 кадров AR0234 без проектора, равномерная выборка 120 кадров
с шагом 5 секунд. Исходный архив SHA-256
`d7e6ffce46a105204c628b950767e66114d73a1fb4cc467637db5b662580836b`.
Черновые рамки построены вручную без просмотра предсказаний моделей. Оператор
проверил все 120 фотографий и поправил рамки; 65 JSON отличаются от черновика.
Архив исправленных LabelMe JSON SHA-256
`2bb99b701c733872cc51e2f6e21e4c66c86438281bee8ae1070fc0418a941fa0`.
В файлах осталось поле `sie_review_required=true` от черновика; факт последующей
проверки подтверждён оператором отдельно в переписке. Архив содержит 100
положительных и 20 пустых кадров, один человек на каждом положительном.

Прогон v2 на исходных JPEG с фиксированным порогом confidence 0.40, NMS IoU
0.45 и критерием совпадения рамки IoU 0.50: TP 99, FN 1, FP 0, TN 20.
Recall presence и localization: 99/100. Precision: 99/99. Единственный пропуск:
`ar0234_000609.jpg` (руки разведены в стороны). Хеш модели v2:
`5583d645afebd3d52706b76655662cb4ce16110b2a0b224af2cc806d0292d07b`.
Прогон выполнен локально на CPU; его замеры времени нельзя переносить на Pi 5.

Для парного сравнения нужен точный файл v1 `best.onnx`, SHA-256
`dde42238b5742f9c0b79c29863c44bc97b678aa75b86a4db5bb602a2d72c259c`.
Один и тот же `vision_core/tools/evaluate_shadow_rgb_blind_onnx.py` проверяет
хеши модели, архива разметки и всех 120 JPEG перед оценкой. Пример запуска:

```bash
python vision_core/tools/evaluate_shadow_rgb_blind_onnx.py \
  --model-version v1 \
  --model /path/to/ar0234_person_upper_body_yolo11n_v1/best.onnx \
  --subset-dir /path/to/annotation_subset_5s_v1 \
  --reviewed-archive /path/to/shadow_rgb_blind_reviewed_20261031.tar.gz \
  --output /path/to/shadow_rgb_blind_v1_20261031.json
```

Это тест детекции и положения рамки на разреженных фотографиях. Непрерывное
сопровождение, глубина, безопасное расстояние и движение тележки не проверялись.
